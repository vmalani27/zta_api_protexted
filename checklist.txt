Kali2: IAM, PEP, PDP (Access Control Core)
------------------------------------------
**Role:**
- **IAM (Identity & Access Management):**
  - Handles user authentication and authorization (Keycloak is implemented)
  - Issues and manages authentication tokens
  - Maintains user and role database (test users are implemented)
  - Implements primary MFA for all user authentication
  - Manages MFA policies and enforcement
- **PEP (Policy Enforcement Point):**
  - Receives all access requests from users/devices (PEP client)
  - Forwards requests to the PEP server for policy enforcement
  - Validates authentication tokens and session state
  - Enforces MFA requirements for sensitive operations
- **PDP (Policy Decision Point):**
  - Evaluates access requests against defined security policies
  - Makes allow/deny decisions based on user, device, context, and compliance status
  - Returns policy decisions to the PEP for enforcement
  - Considers MFA status in policy decisions

**How PEP Client, IAM, PEP Server, and PDP Work Together:**
1. **PEP Client** (on user device) sends an access request with credentials/token to the **PEP Server** (Kali2).
2. **PEP Server** validates the token with the **IAM** (Keycloak) and forwards the request to the **PDP**.
3. **PDP** evaluates the request against security policies (user role, compliance, context).
4. **PDP** returns an allow/deny decision to the **PEP Server**.
5. If allowed, the **PEP Server** grants access to the requested resource; otherwise, access is denied.
