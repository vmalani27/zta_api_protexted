Network Topology Overview
-------------------------

Hardware:
- Raspberry Pi 4 Model B (4GB RAM, 32GB storage)
- Ethernet port (eth0) configured as DHCP server

Software Stack:
- Docker: Hosts and manages microservices (Keycloak, PEP client/server, PDP, protected resources)
- Apache2: Serves web interfaces and static content
- FreeRADIUS: Provides 802.1X network authentication
- Python-based FastAPI PEP client
- Keycloak: Identity and Access Management (IAM)
- PostgreSQL: Persistent storage for Keycloak

Network Flow:
1. **Network Access (Layer 2/3):**
   - Devices connect via Ethernet (eth0) to the Pi.
   - Pi acts as DHCP server, assigning IP addresses.
   - Devices must support 802.1X for network authentication.
   - FreeRADIUS validates user credentials (username, password, secret).
   - Only authenticated devices are allowed network access.

2. **Web Authentication (Layer 7):**
   - Authenticated users are redirected to a web login interface (served by Apache2).
   - Keycloak manages user authentication, including multi-factor authentication, within its own realm.

3. **Access Control & Authorization:**
   - Python-based PEP client interacts with Keycloak to obtain and validate tokens.
   - PEP client sends token to PEP server.
   - PEP server collaborates with PDP to evaluate access policies based on user roles and permissions.
   - Port knocking is required before sensitive service requests are processed, adding an extra security layer.

4. **Protected Resource Access:**
   - Protected resources are hosted in isolated Docker containers.
   - Access is granted only after successful network authentication, web login, port knocking, and policy checks.

5. **Zero Trust Enforcement:**
   - The Raspberry Pi enforces Zero Trust logic, including distributed firewall rules and network segmentation.
   - All internal communications are encrypted.
   - Centralized logging and monitoring are enabled for all components.

Summary Diagram:
----------------
[Device] --(802.1X/EAP)--> [eth0: FreeRADIUS/DHCP on Pi] --(Web Login)--> [Apache2/Keycloak] --(Token)--> [PEP Client (FastAPI)] --(Port Knocking)--> [PEP Server] --(Policy)--> [PDP] --(Access)--> [Protected Resource (Docker)]

Key Points:
- Layered security: Network authentication → Web authentication → Role-based access control
- Port knocking and nonce/session management for replay protection
- All services managed via Docker for isolation and scalability
- Pi acts as the central orchestrator for Zero Trust
